Evidence that an AI red-team test was fair.

Bayora keeps the attacking team, the defending team and the model behind enforced walls, catches leaks with canaries that name the leaker, and seals every event in a log that witnesses co-sign. The run ends with a custody receipt that anyone can check.

Why a safety finding can be void

Red team, blue team and the client model share infrastructure. One leak between them quietly invalidates the result, and today nobody outside the lab can check that it didn't happen.

Defenders see attacks

If the blue team glimpses red's payloads before the test, the defence looks stronger than it is and the finding is worthless.

Container, file and network paths

Shared caches talk

On a shared model server, one tenant can work out another's prompt from how fast cached text comes back.

NDSS 2025, prompt leakage via KV-cache sharing

Records can be rewritten

Without a tamper-evident log, results can be edited after the fact, and the EU AI Act now asks providers to document adversarial testing.

EU AI Act, Art. 55(1)(a)

The protocol, in order

Each stage leaves evidence in the log. The receipt at the end binds all of it, so a verifier can check the whole chain without trusting the people who ran it.

    Detect

    Audit

  5. After

    Verify

    Anyone checks the receipt, the witness quorum and the teams' reveal against their commitments.

    What the red team tried

      Every secret carries canaries only Bayora can mint. Bayora leaks fake ones on purpose through every monitored channel, in many disguises, and counts how many each scanner catches. A canary that turns up without being planted is raised as a possible real leak.

      Catches by disguise and channel

      all caughtsome caughtnone caught: residual risk

      Recall per scanner

      On a shared model server, tenant B times its own prompts to guess which of eight secrets tenant A's prompt contains. Bayora runs this attack against a real model before the evaluation. It passes only if the salted attacker does no better than guessing and the server reused no cache across tenants.

      What it means

      Every event is appended to a Merkle log. Checkpoints are signed by the operator and co-signed by witness processes, which refuse to sign two different histories. In this build both witnesses run on the operator's machine.
